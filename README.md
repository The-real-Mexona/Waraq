# ورق 0.4.3 — الروابط وأدوات التنقل

أغلق الإصدار السابق، وفك الحزمة كاملة ثم شغّل Waraq.exe من المجلد الجديد. لم يُرفع البرنامج إلى أي خدمة مشاركة.

## الإضافات

- **روابط الويب والبريد المضمّنة:** النقر على مساحة الرابط داخل الصفحة يفتح المتصفح الافتراضي، أو تطبيق البريد لروابط mailto. يظهر عنوان الوجهة عند تمرير المؤشر، ويمكن الوصول للرابط بالكيبورد وفتحه بـ Enter.
- **الروابط الداخلية:** الانتقال إلى الصفحات والوجهات المسماة، بما فيها موضع النص والتكبير في وجهات XYZ وملاءمة الصفحة في الوجهات المدعومة.
- **الفهرس:** يستخدم نظام التنقل نفسه؛ روابط الفهرس الخارجية أصبحت قابلة للفتح أيضاً.
- **عناوين الويب المكتوبة كنص:** اكتشاف العناوين البسيطة التي تبدأ بـ https:// أو http:// أو www. ضمن عنصر نص واحد، دون تغيير محتوى PDF. لا يتم تخمين روابط من صور ممسوحة أو عناوين مقسمة على عدة عناصر نصية أو أسطر.
- **الرجوع والتقدم:** في لوحة «العرض» تجد الرجوع إلى الموضع السابق والتقدم بعده؛ الاختصار Alt+يسار وAlt+يمين. يُحفظ سياق التكبير والعرض أيضاً. هذا السجل يتتبع الانتقال عبر الروابط والعلامات الشخصية، وليس كل حركة تمرير.
- **علامات شخصية:** «العرض ← حفظ موضع القراءة». تُحفظ محلياً لكل بصمة PDF، وتظهر عند إعادة فتح الملف. يمكن الانتقال إليها وحذفها؛ لا تُكتب داخل PDF عند التصدير.
- **معلومات الملف:** الاسم والحجم وعدد الصفحات والعنوان والمؤلف والمنتج وإصدار PDF عندما تتوفر في بيانات الملف.

لنسخ نص يغطيه رابط، اضغط Alt أثناء تحديد النص بالماوس؛ يتوقف التقاط الروابط للمؤشر مؤقتاً. ألوان التظليل والتعليقات تبقى منفصلة عن ألوان الصفحة.

## ما شملته مراجعة وظائف القارئ

النسخة الموجودة كانت تدعم البحث والتحديد والتكبير والملاءمة والمصغرات والفهرس وملء الشاشة واستعادة موضع القراءة والتبويبات. كانت تفتقد تفعيل روابط الصفحة والعودة من الوجهات المرتبطة وعلامات القراءة الشخصية وخصائص الملف؛ أضيفت هذه الوظائف في هذا الإصدار.

هذه مراجعة مركزة لوظائف القراءة والتنقل، وليست ادعاءً باكتمال كل إمكانات PDF: الطباعة المتكاملة، OCR، إدارة المرفقات، تحرير كائنات النص الأصلية العام، التوقيع الرقمي وإدارة الصفحات المتقدمة ليست إضافات هذا الإصدار.

## حدود الروابط والأمان

يُسمح فقط بـ HTTP وHTTPS وmailto، مع تحقق آخر في عملية التطبيق الرئيسية. لا ينفّذ ورق JavaScript المضمّن أو أوامر Launch، ولا يفتح مسارات file أو بروتوكولات تشغيل البرامج. روابط GoToR إلى مستند خارجي ليست مدعومة حالياً. لا تجري معاينة أو جلب للرابط من الشبكة بمجرد عرض الصفحة؛ الاتصال بالخارج يتم في التطبيق الافتراضي عندما تنقر الرابط.

الروابط تحتاج تعليقات PDF فعلية أو عنوان ويب قابل للاستخراج كنص. الشكل الشبيه بالرابط داخل صورة لا يوفّر وجهة يمكن استعادتها بلا OCR أو معلومات إضافية.

## الاختبارات

نجحت اختبارات روابط الويب والبريد والعناوين النصية والوجهات الداخلية والرجوع والتقدم والفهرس والتكبير والصفحات المدورة وحفظ العلامات بعد إعادة فتح الملف وحذفها. اختُبر عرض بيانات ملف تحتوي نصاً يشبه HTML دون تفسيره ككود. اختُبر منع الروابط غير المسموحة ومنع رسائل الفتح من مرسل غير موثوق.

اختبارات رابط التشغيل الخارجي استخدمت بديلاً اختبارياً لفتح المتصفح؛ لم تزُر عناوين الاختبار. التشغيل الفعلي لملف EXE مع متصفح ويندوز الافتراضي يبقى بحاجة إلى تجربة الجهاز، وفق قيد التشغيل السابق، دون تغيير صلاحيات Windows. جودة رسم الصور لم تُخفّض.
